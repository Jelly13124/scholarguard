## Segments

```
1/ 🇺🇸🇬🇧 Turnitin's published false-positive rate is under 1%. Apply it to a 50,000-student campus submitting 5 papers/term — ~2,500 falsely-flagged students/semester. "I didn't use AI" is the most common appeal opening we see now. #USAcademicAppeal

2/ False positives are not random. Three things show up disproportionately in flagged work:
• Heavy Grammarly Premium use (rewrites toward formulaic phrasing)
• Outline-first drafts (templated structure)
• Translation flows (non-native English smoothed by tools)

3/ The instinct on receiving a flag is to write a letter arguing the detector is wrong. This usually loses. The detector isn't wrong about the pattern — but a pattern is not proof of AI use.

4/ What works in successful response letters: reframe from "your tool failed" to "the pattern your tool flagged is consistent with how I normally write". Then prove it. Timestamped drafts. Outline files. Edit history. Peer review trail.

5/ Faculty boards aren't usually debating detector science. They're looking for an evidence trail. The case that wins is the one with documented process, not the one with the cleverest argument.

6/ One thing to do today if you write for school: turn on revision history. Google Docs, Word, Overleaf all save it. If you're ever flagged, that history is the cheapest defense you'll find.

7/ More US/UK academic case breakdowns coming — appeals, study strategy, the patterns that actually work. Follow if you write things that need to land. #UKAcademic
```
