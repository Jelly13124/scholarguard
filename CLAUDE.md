## What this repo is

**The ScholarGuard** — a faceless brand publishing anonymized US/UK academic appeal case breakdowns on X and Instagram, with a 3-tier paid service ladder fed by a free lead-magnet → email-nurture funnel.

- **Operator:** 1 person, China-based, English-fluent in writing
- **Time budget:** 3-5 h/week steady state
- **Money budget:** $0-30/month
- **Target audience:** Native English-speaking US and UK university students
- **Out of scope:** Overseas Chinese students (handled by sister brand at xueyouxingtu.com)

This repo holds **two parallel subprojects** in the same git tree:

| Path | Stack | Purpose |
|---|---|---|
| `scripts/`, `tests/`, root | Python 3.13 + pytest + requests | Buffer GraphQL API client, case anonymization pipeline, content automation |
| `web/` | Vite + React 18 + Tailwind | Marketing website at `thescholarguard.com` (domain not yet purchased) |

When the user says "the site," "the website" → they mean `web/`.
When they say "posts," "Buffer," "the bot," "the pipeline" → they mean the Python side.

## 🚨 HARD LEGAL GUARDRAILS — never cross

These are baked into spec, code, and copy. **Do not deviate without explicit user permission.**

1. **Never imply legal advice.** Always note "We analyze patterns from real cases. Always consult licensed counsel for legal questions."
2. **Never promise outcomes.** Use "outcome data" language, not "guaranteed."
3. **No fake testimonials, photoshopped reviews, or invented personas.** (FTC $51k/violation; UK CMA equivalent.)
4. **No public listing of ghostwriting service.** DM/word-of-mouth only. Public copy must say "We do not write papers, essays, or coursework."
5. **No AI-generated faces or fabricated credentials.**
6. **Disclose nothing identifying about real clients.** Anonymization is MANDATORY before any case becomes content.

The Services page, About page, and Footer all carry these guardrails explicitly. Preserve them when editing copy.

## How to make changes

### Python pipeline

```powershell
# Activate venv
.\.venv\Scripts\Activate.ps1

# Run tests (integration — hits live Buffer API in draft mode)
pytest tests/

# Drop a case → anonymize manually following cases/CASE-TEMPLATE.md
```

### Website

```powershell
cd web

# Dev server (hot reload)
npm run dev                 # → http://localhost:5173

# Production build (sitemap + vite build + Edge prerender all 6 routes)
npm run build               # → web/dist/

# Preview production build locally
npm run preview             # → http://localhost:4173

# Just regenerate sitemap
npm run sitemap

# Just regenerate OG image (after editing scripts/og-template.html)
# Manual: Edge --headless --screenshot=public/og-default.png --window-size=1200,630 file:///.../scripts/og-template.html
```

### Deploy (Cloudflare Pages — once user sets it up)

Build settings:
- Build command: `cd web && npm install && npm run build`
- Output directory: `web/dist`
- Production branch: `master`

⚠️ Cloudflare build containers don't have Edge installed → prerender step fails gracefully (`process.exit(0)`) and SPA-only build ships. Acceptable degradation.

## How to commit

**This repo has NO global git config.** Bare `git commit` fails with "Author identity unknown."

**Use inline `-c` flags every commit:**

```bash
git -c user.email="noreply@thescholarguard.com" -c user.name="The ScholarGuard" \
  commit -m "..."
```

Commit message style (matches prior commits):
- `feat(scope): description`
- `fix(scope): description`
- `docs(scope): description`
- `chore(scope): description`

Include `Co-Authored-By:` trailer when AI-assisted:
```
Co-Authored-By: Claude Opus 4.7 (1M context) <noreply@anthropic.com>
```

GitHub remote: `https://github.com/Jelly13124/scholarguard` (master branch).

**Never push to remote without user's explicit "push" confirmation.**
